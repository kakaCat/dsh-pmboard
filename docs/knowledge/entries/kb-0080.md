## 结论
立项弹框失效修复：宿主 askTimed 的 callId=undefined 使弹框请求被网关判 not lossless JSON data 而拒收；移除透传改走官方 ask() 路径 + 源头修 description:undefined + 通道边界无损清洗，实测弹框恢复（两段弹框渲染、作答、立项成功）。
