## 结论
看板运行圈的「在跑」判据扩为「绑定窗口在跑回合 ∪ 新鲜推进锁」：投递式后台 run 跑子卡链时也点亮圆圈；两种成因共用一个圈（视觉零变化），同次就地取代领域篇红线中 advanceLockAt 一条（executions 判据仍禁用）。
