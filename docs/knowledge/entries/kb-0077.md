## 结论
agent 可见文案不许漂移：七组文案/契约漂移（死路径、手写问数、submit「五类」漏 prototype、历史叙事、长文本注记误挂、拦截清单枚举、monorepo 残留）清零，并把「路径可达 + 禁词前缀」探针挂进 prompts:check——文案修复从"靠体检发现"变成"提交即被拦住"。
