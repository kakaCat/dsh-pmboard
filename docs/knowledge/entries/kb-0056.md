## 结论
原型豁免（prototype_exempt）的消费点补齐：拆分覆盖门的 UI 卡原型锚点维也消费豁免——豁免生效 ∧ 无已登记原型产物 ⇒ 整维跳过，未生效照旧拒、已交原型照旧要求锚点；判据复用既有单点，不再需要把端侧谎报成 fullstack 绕行。
