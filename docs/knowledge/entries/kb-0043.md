## 结论
插件包自带宽 7 份 UI/UX skill 资产（含可检索主 skill）；子代理读不到包内路径，故由 reqboard_skill_install 投放到 <会话工作区>/.dsh/skills 并回执绝对路径；需求分析节点只注入一小节「原型工作原则」（可裁、只进重档），主 agent 不背全文与数据。

## 适用条件
要给子代理提供大体积资产、或要往某节点注入新纪律时（先读这条，别重复踩坑）：
- 资产 > 数百 KB 且使用者是子代理 ⇒ 走「包内是源 + 投放 + 回执路径」，不要塞进注入文本。
- 要往提示词体系加一节 ⇒ 先想清楚它该不该占**每一轮**预算；要可裁、要只进需要它的难度档。
