## 结论
把「是不是同一个项目」从路径字符串比较换成项目 id 相等（session → projectId → workspaceRoot）：看板、产物扫描、知识层自举与子代理根一律按项目身份定位；同项目多窗口天然归一，跨项目派席/交接/改绑当场拒绝并说清两个项目与判据来源；存量 74 条不迁移不拒写，老 SQLite 库开库幂等补列，退回去只需摘掉项目表装配。
