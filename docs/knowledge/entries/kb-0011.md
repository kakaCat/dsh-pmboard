## 结论
长文本工具入参写法约定：把「怎么写才不踩 JSON 转义坑」收敛为一处共享常量 LONG_TEXT_ARG_NOTE（三锚点：短句 ≤60 字 / 需引号用「」/ 超长拆多次调用）+ 覆盖清单 LONG_TEXT_FIELDS（15 条 / 8 工具），各工具 description 引用、遍历用例守覆盖、实施片段加「汇报自检」；入参 schema/返回体/错误码零变更，适配器侧「整轮失败粒度」明确在边界外另立需求。
