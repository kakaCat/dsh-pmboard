## 结论
拆分节点从此先算容量再拆：卡片体量声明（改几个文件 / 几条验收锚点 / 多少字符，声明不得小于证据）+ 超容量软门禁（只报不拒；返回体 / 批准弹框 / 计划文档标记三通道同源可见，标记批数必须相等，门禁读实际提交路径）；余量读数只读上屏并标注「非门禁判据」，拿不到就说拿不到、绝不补 0；老数据零迁移。
