## 结论
会话头部流程图的 token 读数不再随窗口变窄而消失：窄档常显「需求累计 Token」（口径改走与节点同源的合计，修掉记录级总计漏进行中阶段的坑），探针新增「各档可见 token ≥ 1」硬断言。
