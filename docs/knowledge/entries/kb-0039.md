## 结论
看板可改每阶段回合上限（四级来源、同步快照、改小不掐断在跑那一轮、内置默认下限 5），可把台账切到 SQLite 库（一次性票据的人工确认门、否定作答不可消费、迁移先备份再建库且失败不伤源数据），并在系统记录里留档（路径档案 / 后端使用史 / 迁移与回滚 / 版本一致性）。
