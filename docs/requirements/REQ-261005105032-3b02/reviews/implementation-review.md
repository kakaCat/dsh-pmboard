## 3. 复核中提出的重要纠正（本窗口自己改的，不是转述）

1. **门自己绿了**（t11 探针）：自动发现会把落盘骨架补登成 `kind=prototype`，存在门只按 kind 过滤 → 只落骨架、人一个字没填，三门全 PASS → 收紧为**只认显式登记**，并修掉配套的**登记升级死结**。
2. **本需求被自己的时序门拦住**（t21 探针）：E2E 读数被压成布尔，存量需求都没有测试策略表 → 改为「**无表即读数未知，不判**」并补回归锁（改回必红）。
3. **卡面验收自相矛盾**（t20 报告 + 我实测）：既要求命令含重生成、又要求"改了源不重生成必须失败" → 加性补只校验守卫。
4. **基线缺陷**（不属于任何卡）：`tests/receive-mark.test.ts` 类型错误（HEAD 自带）1 行修掉；`template-address.test.ts` allowlist 两条豁免。
