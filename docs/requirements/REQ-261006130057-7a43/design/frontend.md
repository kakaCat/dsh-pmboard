## 验收面板 RTM 列表（蓝本 `#FR-8`，D-4/D-8） `serves: FR-8`

- **汇总行**：「FR 验收进度 a/b 通过 · c 待裁决 · d 不通过」+ 右侧版本签
  （「验收单 vN · 返工续验只含未过项」/「材料已交·待裁决」）。
- **主表**（`data-rtm-table`）：列 = FR（展开钮 ▸/▾ + 编号 + 名称）｜覆盖链（设计/任务/测试
  三枚 chip：覆盖=绿底「设计 ✓」、缺=灰底描边「测试 ✗」；无 RTM 数据整列不渲染）｜怎么验
  （verification 一行截断 + title 全文）｜验收状态（✅ 通过 / ✖ 不通过 / ⏳ 待裁决 / 灰 未复核；
  `needsHuman` 旁挂「无法自验·需人工」琥珀旗）｜裁决·意见（待裁决行给「通过/不通过」小按钮，
  走既有验收单逐项裁决链路；已判行显示时间+人+意见一行）。
- **行展开**（`data-fr-detail`）：该 FR 逐项的实际结果（命令+输出摘要）/ 证据清单 /
  `needsHuman + humanReason`；默认全收，任一可展开。
- **下部**：材料摘要 + 证据清单（来自 `materials`）；历史版本（v2 待裁决 / v1 已退回逐行）。
- **空态**：无 sheet 三行解释（没交/找谁交/交了会看到什么）；items 空单独一句。不画空表格。
- **无 tracking 降级**：退化为逐项平铺（按 fr_id 能归组的归组），覆盖链列不渲染——
  RTM 是增强层，缺失不打断（FR-9）。
