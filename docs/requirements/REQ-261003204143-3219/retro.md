## 根因（机制性，已沉淀）

不是"某个人漏改一行"，而是**嵌套键没有防线**：静态契约扫描只比顶层 return 键，
单测断言取值不过 schema——两层既有机制都照不到 `answers.*` 这类嵌套对象。
修复把防线补在嵌套层：键清单一处共享常量，tsc（Record 派生）+ 生成式 schema + 键集断言三方同源。
沉淀去向：`docs/architecture/project-manual.md` 机制备忘「弹框问项与输出 schema 的三方同源」。
