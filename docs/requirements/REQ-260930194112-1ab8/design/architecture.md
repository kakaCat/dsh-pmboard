# REQ-260930194112-1ab8 架构设计 · 列表视图自适应层 serves: FR-1, FR-2, FR-3, FR-4, FR-5, FR-6

> 目标：在「列表视图」的表格与容器之间加一层**宽度自适应层**，把「列宽由浏览器自动算法决定」改成「列宽由显式契约决定」。纯前端展示层，签名与数据零变更。

## A-1 · 现状与故障链 serves: FR-1, FR-3, FR-5

```
buildListView(state)                     浏览器自动表格算法                   用户看到
┌────────────────────┐   8 列无宽约束   ┌──────────────────────┐   宽度不足   ┌──────────────┐
│ <table> 8 列        │ ───────────────► │ 列宽 = f(min-content)│ ───────────► │ 中文逐字竖排  │
│ 无滚动容器          │                  │ CJK/连字符可断到 1 字 │              │ 按钮溢出重叠  │
│ 无 min-width        │                  └──────────────────────┘              └──────────────┘
└────────────────────┘
```

| 失效点 | 位置 | 后果 |
|--------|------|------|
| 无滚动容器 | `buildListView` 返回的 `.dsh-pm-list` 直接含 `<table>` | 无兜底，只能压列 |
| 无列宽下限 | `styles/board.ts` `.dsh-pm-table` 只有 `width: 100%` | 宽度不足即压缩 |
| 关键列可断行 | 无 `white-space` 规则 | ID 断连字符、中文竖排（FR-1 反例） |
| 操作列可压缩 | `.dsh-pm-list-actions` 内层 `.dsh-pm-card-actions` 可收缩 | 按钮叠字（FR-3 反例） |
| 标题列硬上限 | `.dsh-pm-td-title { max-width: 380px }` | 窄宽度下标题每行仅 5~7 字 |

## A-2 · 目标结构（新增一层）+ 断点让位 serves: FR-4, FR-5

```
.dsh-pm-list
├── .dsh-pm-list-toolbar          排序 / 每页 / 计数（不变）
└── .dsh-pm-table-wrap   ◄── 新增：overflow-x: auto（低于 720px 时横向滚动）
    └── .dsh-pm-table    ◄── 新增：min-width: 720px（保底，不压扁）
        ├── thead > tr > th[.dsh-pm-col-*]
        └── tbody > tr.dsh-pm-list-row > td[.dsh-pm-col-*]
```

| 可用宽度 | 行为 | 可见列 |
|----------|------|--------|
| ≥ 1180px | 与现状一致（零变化） | 全部 8 列 |
| 880 ~ 1179px | 次要列让位 | ID / 标题 / 状态 / 进度 / 操作 |
| 720 ~ 879px | 再让一列 | ID / 标题 / 状态 / 操作 |
| < 720px | 表格横向滚动（保底） | 同上一档，滚动查看 |

断点机制：`@media (max-width: …)`（视口宽度）。**不引入** JS 宽度监听、`ResizeObserver`、容器查询——本仓列表视图是整页视图，视口宽度即面板宽度（2026-09-30 实测标本：840px 视口复现用户截图同款塌陷）。

## A-3 · 分层职责 serves: FR-4, FR-6

| 层 | 文件 | 本次改动 | 职责边界 |
|----|------|----------|----------|
| 视图层 | `src/client/views/board.ts` | `buildListView` 加滚动容器；`renderListCard` 给 4 个单元格加列类名 | 只产出 markup，不含宽度判断 |
| 样式层 | `src/client/styles/board.ts` | 新增 wrap/nowrap/弹性/不可压缩规则 + 两个断点段 | 全部宽度行为都在 CSS |
| 探针 | `scripts/list-responsive-probe.mts` | 新增 | 复跑式布局回归门 |

## A-4 · 回滚路径 serves: FR-6

- 改动集中在 2 个源文件 + 1 个新增脚本，**无数据迁移、无配置开关**；回滚 = 还原这 3 个文件。
- 宽屏（≥1180px）不命中任何新增的断点规则，只命中 nowrap 与操作列不可压缩——两者对宽屏渲染为等价规则（A-5 不变式）。

## A-5 · 宽屏零变化的不变式 serves: FR-6

≥1180px 时下列量法必须与改动前一致：列数（8）、列序、`colspan="8"` 分组头、`.dsh-pm-td-title` 上限（380px 恢复为该档上限）、操作列按钮数与文案。

- 探针在 1680px 档断言 `problems=NONE`，并断言三个让位列**可见**（`getClientRects().length > 0`），防止断点误命中把宽屏也砍了列。
