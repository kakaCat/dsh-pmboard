| 状态 | 判据 | 是否可点开 |

| `pending` | 命中候选根 且 未落章 | 是 |
| `unregistered` | 文件在盘上但台账无登记（设计文档集） | 是（文案说明"未登记"） |
| `file-missing` | 候选根可用、文件逐根都找不到 | 否（划线） |

## 台账零变更 `serves: FR-5`

- `RequirementRecord.workspaceRoot` / `docBasePath` 既有字段直接复用，**不新增、不改写**。
- `absPath` 是**读时投影**，不落库、不进 `artifacts.json`（否则同一份台账在不同机器上会互相覆盖出错误的绝对路径）。
- 旧分片（冷侧归档记录）无需回填：候选根解析发生在读侧。

## 多根命中的确定性 `serves: FR-2`

- 候选根**去重后按固定序**（需求根 → 会话根 → cwd），同一输入必然同一结果，测试可断言。
- 同一相对路径在两个根下都存在时取**序首**（需求根），页面同时给出相对路径小字，避免"看到的绝对路径与台账登记的不是一处"。
