## U-1 · 看板用户扫泳道判阶段 serves: FR-2

- 操作：打开实施节点「泳道」页签，看「测试中」列的卡片。
- 修复前：卡片浅蓝（原始 status=in_progress），与列头橙色矛盾。
- 修复后：卡片浅橙，与列头色点同色——颜色即可信的阶段信号。

## U-2 · 看板用户对照 DAG 与泳道 serves: FR-1, FR-2

- 操作：同一切换 [DAG]/[泳道] 两页签，定位同一张父卡。
- 修复前：泳道浅蓝、画布浅蓝或浅绿（色板 B 错位），两视图颜色语义不一致。
- 修复后：两视图同一阶段同一色（同引 STAGE_COLORS），DAG 节点色 = 泳道卡片色 = 列头色点色。
