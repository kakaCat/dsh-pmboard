## 四、风险与注意

- **别动 `tokenTotals` 语义**：摘要里没有 token 快照字段，若要在新载荷里保留该派生视图，
  必须另想"不读全文"的算法（否则又把读放大请回来）——**这是本卡最需要先想清的一点**。
- `listSummaries` 的规范序是 `updatedAt` 倒序；旧载荷是 `createdAt` 升序（追加序）。
  客户端若依赖追加序，需在 client 侧显式排序，不要再让服务端逐条取全文。
- 每步单文件验证、**禁用全仓自动批量**（本需求 de124 的教训：设计文档 §91 第 ㉔ 条）。
