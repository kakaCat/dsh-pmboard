# t-07b058 验收⑥ 施工规格：只读「假 SQL 形状」替身

> 目标：`tests/reqboard/store-contract.test.ts` 的 `IMPLEMENTATIONS` 加第三行，跑**同一份 36 条断言**全绿，
> 证明「端口真的可替换、不泄漏存储细节」——DB 适配器可直接照这份入场。
> 现状：文件头第 7 行仍写着「t11 再接假 SQL 替身」，即该槽位**尚未接入**。

## 一、必须实现的成员（`RequirementStore`，`src/application/ports.ts`）

读侧（36 条断言实际调用的）：

| 方法 | 说明 |
|---|---|
| `get(id)` | 热侧命中返回记录；命中**冷侧（archived）**也要能读（用例：深链要打得开） |
| `getSummary(id)` | **投影**：不含 `BIG_FIELD_KEYS`（大字段键集来自 `src/domain/requirement/RequirementSummary.ts`） |
| `listSummaries(filter?)` | 缺省 `scope=active`（归档不进默认结果）；支持 `ids` / `limit` / **`cursor` 分页** |
| `listComments(id, opts?)` | 支持 `since` / `limit` |
| `listHistory(id, opts?)` | 支持 `limit` |
| `head()` | 返回 `{ revision, schemaVersion }` |
| `headAfterDrain()` | 同上（"已落盘"语义） |
| `peekSummaries()` | **同步**；许可区恰好三项（见 ports.ts:308~326 的纪律注） |
| `peekFacts()` | **同步**；比 `peekSummaries` 多带 `description` |

写侧：声明 `suites: ['read']`，写方法可 `throw new Error('read-only double')`（读套件不会调）。

## 二、实现要求（"假 SQL 形状"的含义）

```
· 内部用一张"表"（数组即可）持有记录，但**只经端口方法暴露**——即替身里不得把内部数组
  当返回值直接交出去（否则就证明了"端口泄漏存储细节"的反面）。
· 分页游标：自造一个不透明字符串（如 base64('offset:12')），并保证
  ① 末页不返回 nextCursor ② 越界 cursor 返回空页且不抛错（与分片实现同语义）。
· 摘要投影一律走 `summarize()`（`src/domain/requirement/RequirementSummary.ts` 的现有纯函数），
  不要自己手写字段拷贝——否则第三个实现与另两个会漂移。
```
