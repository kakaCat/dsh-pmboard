## TL;DR

给数据加**项目维度**，再让每条取路径与**写路径**的操作**按该条记录自己的项目**解析；错配**响亮失败**，绝不静默写到别的项目。

```
   处理入口
      │ 拿到记录（或记录集）
      ▼
   projectRootOf(record, fallback)          ← 唯一口径（缺失则兜底 + 标注）
      │
      ├─ 遍历类：只处理本次项目的记录（别人的跳过 + 计数回报）
      ├─ 取路径类：按记录的项目根解析（扫描 / 落库 / 写 RTM / 写完工记录 / 读知识层）
      └─ 写盘前：即将写的根 ≠ 记录声明根 → REQBOARD_PROJECT_ROOT_MISMATCH（给两个绝对路径）
```
