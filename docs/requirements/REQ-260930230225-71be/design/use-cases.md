# REQ-260930230225-71be 用例设计 · 会话头部的三种使用场景 serves: FR-1, FR-2, FR-3, FR-4, FR-5

> 场景来自用户原话：「会话框的右上边流程节点大小没有适配屏幕，位置希望移动到模式后面」。
> 三条用例覆盖「看进度」「点节点」「异常降级」，全部是既有交互，不改行为、只改位置与宽度。

## U-1 · 主用例：扫一眼知道这个会话做到哪了 serves: FR-1, FR-3

| 步 | 角色动作 | 系统响应 |
|----|----------|----------|
| 1 | 用户打开一个已绑定需求的会话 | 标题行渲染：`会话标题 / [标准模式] [●─●─◉─○─○─○─○ 3/12]` |
| 2 | 用户扫视头部 | 圆点四态给出「已完成 / 当前 / 未到 / 本分类跳过」，计数给出任务进度 |
| 3 | 窗口变窄（分屏、侧栏展开） | 按 A-2 档位表逐级降级：先去 token，再去连线与非当前节点名，最后只留圆点 + 计数 |
| 4 | 窗口变宽 | 回到全量渲染，位置始终在模式标签右侧 |

成功判据：任一档位上「当前节点」与「done/total」都可读到；标题行不出现横向溢出（T-2 A1/A3）。

## U-2 · 分支用例：点节点看该阶段详情 serves: FR-2, FR-4

| 步 | 角色动作 | 系统响应 |
|----|----------|----------|
| 1 | 用户点击任一圆点 | 该圆点 `data-selected="true"` 高亮，下方展开详情面板 |
| 2 | 面板出现 | 宽档（容器 > 620px）：面板从图表右缘向左展开；窄档：面板固定到视口右上 |
| 3 | 用户点击面板外 | 面板关闭（既有 `mousedown` 外部关闭逻辑不变） |
| 4 | 用户点面板内的产物链接 / 看板入口 | 打开右侧栏文档 / 切到看板页（既有委托监听不变） |

成功判据：六档视口下面板包围盒都在视口内（T-2 A4），且既有三条委托监听（视图切换 / 打开文档 / 看板入口）行为不变。

## U-3 · 异常与降级用例 serves: FR-1, FR-3, FR-5

| 场景 | 期望行为 | 判据 |
|------|----------|------|
| 会话未绑定需求 | 组件返回 `null`，座位不占空间，标题行与现状一致 | TC-6 + 肉眼 |
| 进度接口失败 / 超时 | 静默不渲染该会话的图（不打断会话），下一个 15s tick 自动重试 | 现状语义不变 |
| 会话已无进行中需求（`closed`） | 渲染最近完成锚点，芯片降透明度（`.is-closed`） | 现状语义不变 |
| 分类跳过某些节点（如 bug 无设计） | 跳过节点圆点显示 `—` 且降透明，与「未到」区分 | TC-5 的 skip 断言 |
| 窗口极窄（< 400px 容器） | 图表内部横向滚动，标题行仍不溢出 | T-2 A1 |
