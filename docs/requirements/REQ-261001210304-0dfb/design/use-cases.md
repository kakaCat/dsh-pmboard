# REQ-261001210304-0dfb 用例设计 · 读图不被打断 `serves: FR-1, FR-2, FR-3, FR-4`

> 视角：**会话里的用户**。每个用例都写清"用户做什么 → 期望看到什么 → 现状会怎样（反面）"。
> 术语：**一轮刷新** = 5 秒兜底轮询命中一次，或一个任务事件（task-moved/created/updated/removed）到达一次加速刷新。

## UC-1 调好视图后继续盯进度 `serves: FR-1`

- **谁 / 何时**：用户展开「实施」节点，把方向切成**横向**、打开**关键路径**、把某个卡**钉住**高亮上下游，然后放着不动盯进度。
- **期望**：接下来每一轮刷新后，图仍是横向、关键路径仍亮、钉住仍在；数据（卡的状态/进度）照常更新。
- **现状（反面）**：下一次刷新即回纵向、开关熄灭、钉住清空（探针 A 段实测：`horizontal/true/true/'t-b'` → `vertical/false/false/null`）——用户一天里要重调几十次。
- **边界**：钉住的卡在新数据里被删掉时，高亮自然失效（不报错、不残留脏高亮）。

## UC-2 切到泳道、滚到中段继续看 `serves: FR-2`

- **谁 / 何时**：用户点「泳道」页签按环节看卡，或留在 DAG 里向下滚到第 3 层看依赖；两者都不希望被打断。
- **期望**：刷新后仍停在泳道页；DAG 里滚动位置保持在同一位置（不跳回顶部）。
- **现状（反面）**：页签态只活在 DOM class 上、滚动位置只活在容器元素上，整段 innerHTML 重建后两者一起归零（用户截图：滚动条已在中段，刷新即回顶）。
- **边界**：数据量变化导致图变短时，滚动位置被浏览器夹取到最大可滚范围（可接受，不做"锚定某张卡"的复杂恢复）。

## UC-3 数据真的变了（任务推进）`serves: FR-1, FR-2, FR-3`

- **谁 / 何时**：agent 推进了一张卡（`task-moved`）→ 面板数据变化，`__html` 真的不同。
- **期望**：图按新数据重画（卡变绿、进度数字更新），但**用户的选择与阅读位置仍在**（方向/开关/页签/滚动保持）。
- **现状（反面）**：与 UC-1 同款归零；且因"数据时间"每轮都变，**没变数据时也在重建**。
- **备注**：这条区分了"该重建"（数据变化）与"不该重建"（只是刷新了时间戳）——FR-3 消掉后者，FR-1/FR-2 承担前者的无感恢复。

## UC-4 切换需求 / 关闭面板 / 重载页面 `serves: FR-4`

| 动作 | 期望 | 依据 |
|------|------|------|
| 面板里从 A 需求切到 B 需求（会话绑定变了） | B 需求是**初始态**，不继承 A 的横向/只看主线/页签/滚动 | 键含需求 id（A5 判据） |
| 关闭面板再打开（同一需求） | 仍是上次的视图（方向/开关/页签/滚动）；数据重新拉取 | 记忆在内存保留，重开命中同一键 |
| 浏览器 F5 重载 | 回初始态（明确接受，不做持久化） | 需求「边界·不做」第 3 条 |
| 另一个标签页打开看板 | 互不影响（各自页面内存） | 记忆不落盘、不跨窗口 |

## UC-5 异常态与降级 `serves: FR-3`

- **刷新失败**：面板头出红条（「刷新失败：… · 显示的是 HH:MM:SS 的旧数据」）——**允许这一次重建**（异常态非常态）；
  重建后方向/开关/页签/滚动仍按 FR-1/FR-2 恢复，用户不会"又丢一次"。
- **插件已更新提示**：出现「插件已更新，点此刷新」按钮，同样属异常态一次性重建，处置同上。
- **无画布 / 无任务**：沿用现状（空态占位 / 不挂画布）；记忆表不因此产生半截状态（写入只发生在有 viewer 时）。

## 状态流转（用户视角） `serves: FR-1, FR-2, FR-4`

```
打开面板 ──► 记忆为空 ──► 初始态（纵向 / 开关关 / DAG 页 / 滚动 0）
   │
   ├─ 用户调视图 ──► 记忆被写（dispose 写 DAG 四项+滚动；点页签写 tab）
   │
   ├─ 一轮刷新（数据未变）──► __html 不变 ──► DOM 不动 ──► 视图原样（FR-3）
   │
   ├─ 一轮刷新（数据变了）──► 整段重建 ──► 按记忆回填 initial + 工具条同步 + 滚动恢复 + 页签恢复（FR-1/FR-2）
   │
   └─ 切换需求 ──► 换键 ──► 初始态（并清掉上一需求的键）
```
