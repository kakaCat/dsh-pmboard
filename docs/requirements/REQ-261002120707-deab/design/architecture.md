## 组件清单 `serves: FR-1, FR-2, FR-3, FR-4`

| 组件 | 职责 | 形态 | serves |
|---|---|---|---|
| 场景脚本库 | 描述用户消息序列、环境种子、期望 | 每用例一份 YAML | FR-2 |
| 终态断言器 | 比对台账快照与期望终态 | 断言 YAML + 人工/脚本执行 | FR-1 |
| 轨迹断言器 | 校验工具序列有序包含、步数预算、循环检测 | 断言 YAML + 人工/脚本执行 | FR-1 |
| LLM 评审器 | 按 rubric 给产物语义打分，2 次取均值 | rubric Markdown + 评审提示词 | FR-1 |
| 评分汇总 | 维度加权、pass^k、红线一票否决、档位 | 计算公式（见 interfaces.md） | FR-3 |
| 报告 | 维度雷达 + 明细 + 红线 + 失败轨迹摘录 | Markdown 模板 | FR-4 |
| 回归集 | 历次失败用例固化，下轮必跑 | regression/ 目录 | FR-4 |

## 目录布局 `serves: FR-2, FR-4`

```
eval-suite/
├── README.md                 # 套件总览 + 执行入口说明
├── scenarios/                # 36 条场景脚本（A1…G4，一文件一用例）
├── assertions/
│   ├── ledger/               # 台账终态断言（与场景同名）
│   └── trajectory/           # 轨迹断言（与场景同名）
├── rubrics/                  # LLM 评审 rubric（产物类用例：C5/E1/E3/E5/G2）
├── calibration/              # 人工标注校准样本（≥10 条）
├── regression/               # 失败回流回归集
├── reports/                  # 历次测评报告
└── runbook.md                # 执行规程（备环境→放 agent→取断言→评分→报告）
```

## 关键设计决策 `serves: FR-1, FR-3`

| 决策 | 选择 | 理由 |
|---|---|---|
| 断言与场景分离 | 场景写「做什么」，断言写「怎么判」 | 场景稳定、断言可随插件演进独立修订 |
| 台账断言用声明式 YAML | 路径+期望值+比较符 | 无代码依赖，人工也能逐条核 |
| 红线用例单独标记 | `severity: redline` 字段 | 汇总时一票否决，不混入加权 |
| 本需求只交付内容与规范 | 执行器工程化另立需求 | spike 边界，避免范围蔓延 |
