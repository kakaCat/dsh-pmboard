## 场景 UC-1：打开详情（一屏答四问） `serves: FR-3, FR-4`

**前置**：需求处于任意在途状态。
**步骤**：从看板点卡进入详情。
**期望**：
1. 只发 1 个请求（`report`）+ 默认 Tab（`trunk`）；
2. 首屏（1200×800，不滚动）可见：需求身份、8 态阶段条、**一句话结论**（在跑什么 / 谁在跑 / 几件事等人 / 下一步谁动手）、**缺口清单**、**操作条**；
3. 缺口里出现的每一项都能指到 source（条款 / 产物 / 断链 / 挂起确认）。
**失败态**：需求不存在 → 「未找到」；台账不可读 → 「不可用 + 原因」（不静默弹回看板）。

## 场景 UC-2：切 Tab 深挖（懒加载 + 不重置） `serves: FR-11`

**步骤**：依次点 汇报 → 文档 → DAG → 对话 → Token → 提示词，各看几秒；期间让 agent 继续跑（台账 revision 变更）。
**期望**：
1. **每个 Tab 只在点击后发请求**；
2. 已看过的 Tab 再切回不重复请求（同 revision 内走内存缓存）；
3. revision 变更时只刷新**当前 Tab + 头部**；滚动位置、已展开的正文/折叠段**保持不变**；
4. 任何列表都不出现内层滚动条。

## 场景 UC-3：接手（我从哪接） `serves: FR-6, FR-9`

**前置**：上一个窗口断过线、交接过一次。
**步骤**：新窗口打开同一需求。
**期望**：
1. 对话 Tab 里能看到系统消息：`窗口交接：w-A → w-B`、`中断：<原因原文> · <恢复时间>`、`挂起确认 pc-… ：待作答 · 拦住 <写路径>`；
2. 系统消息措辞与台账原文一致（**未被重新措辞**）；
3. 回填事件带「回填」标，不会被误读成实时发生；
4. 提示词 Tab 能看到本阶段"规定原文 vs 实测注入"与被裁片段。

## 场景 UC-4：审计（谁批的） `serves: FR-7, FR-5`

**步骤**：打开已归档需求 → 文档 Tab → 核验表 + 门禁裁决留痕。
**期望**：
1. 五道门各有 结论 / **方式**（确认弹框 / 看板 / 文字 evidence）/ 时间 / 理由；
2. 核验每项含 **实际结果 + 来源（agent | human）+ 需人工 + 意见 + 裁决**；
3. 被退回的那次能看到**退回理由原文**与「旧批准作废」留痕；
4. 归档块的 合并去向 / 说明书更新点 / 清单对账（已列·豁免·未列）齐全。

## 场景 UC-5：看钱花哪了 `serves: FR-10`

**步骤**：打开 Token Tab。
**期望**：
1. 主视图是**按阶段**（需求分析 / 设计 / 拆分 / 实施 / 验收 / 归档）的表：调用 / 输入 / 输出 / 合计 / 占比 / **每次调用均** / **缓存命中**；
2. 占比合计与总计一致；
3. 下方「可优化点」每条都带**依据数字**（哪段、多少、与谁比）；
4. 快照缺时显示「部分数据（下界）」并列出缺哪些阶段；完全不可得时显示「无 token 快照」——**绝不显示 0**。

## 三档展示面（同一份数据，三种编排） `serves: FR-3, FR-11`

| 档 | 展示面 | 取数 | 放什么 | **明确不放** |
|---|---|---|---|---|
| 一 | 会话头部（一行） | 仅 `report.progress` + `verdictLine` | 阶段条 + 到哪一步 + 卡在哪 | 其它一切（**本需求不改这一档**） |
| 二 | 会话内展开面板 | `report`（head / progress / gaps / actions） | 谁动手 / 缺口 / 任务进度 / 最近对话 | **文档表、成本、提示词正文、DAG 明细**（窄面铺全量＝挤掉对话） |
| 三 | 详情页（本需求主体） | 全部，按 Tab 懒加载 | 头部 + 六个同级 Tab | — |

**档二收敛目标**：现有 `node-panel.ts`（与详情页并列的第二套渲染器）并入同一数据模型，避免继续漂移。

## 权限与只读 `serves: FR-3`

| 席位 | 能看 | 能写 |
|---|---|---|
| owner | 全部 | 全部合法动作 |
| worker | 全部 | 领卡 / 汇报 / 提交产物 |
| **observer** | 全部 | **无**：不渲染写动作按钮（保留查看与跳转） |
| 终态（archived / canceled / done） | 全部 | 无：操作条只留 `← 看板` |

## 不做（与需求文档「边界」一致） `serves: FR-11`

- 不做成"一份报告"（无封面 / 无章节编号 / 无导出）；
- 不展示测评证据（归「测评证据对外接口」另立需求）；
- 不搬会话全文与工具日志（只留人机文本 + 系统消息）；
- 不做移动端适配（只做窄 / 宽两档）。
