## 复核（t-b46944）

| # | 设计条目 | 结论 |
|---|----------|------|
| P-1 | `WINDOW_MODES` 落 shared.ts（不新建文件） | 无偏离 |
| P-2 | `windowInheritanceSchema()` 每次返回新对象 | 无偏离（函数式，与 TaskTreeTool `nodeSchema()` 同款） |
| P-3 | 两处 mode 枚举改引用 | 无偏离 |
| P-4 | 两处 inheritance 子 schema 改引用 | 无偏离（属性表单源；各自 description 保留） |
| P-5 | 只抽这两处，不碰 capture/create 文案 | 无偏离 |

偏离登记（不阻断）：**D-1** 公共函数收一个可选 `description` 形参——
设计只写「抽公共常量」，但两工具该键的 description 语义**不同**（一个「恒出现」、一个「仅新建接管窗口时出现」），
强行统一会把对外契约文案改错；故属性表单源、描述各留。
