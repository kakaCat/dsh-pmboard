如实登记的偏离 / 未落地项
------------------------------------------------------------------------------------------------
① V-A 圆角取舍：卡按 V-A 要求用 12px；为守住「圆角 ≤2 档」放弃了 999px 那一档
   （状态/窗口/计数都收成 8px）→ 圆角 = {12px, 8px}，胶囊元素 0 个。
② V-B / V-C 的「百分比」：标本 DOM 里没有百分比文本，CSS 无法推算，**不合成假数字**；
   进度用「线长 + 刻度 + 当前阶段名（真实文本）」表达。
③ FR-8 的 ✓/▸ 前缀在 V-A / V-C 由 ::before 承担（受"同一份标本、只换 CSS 层"约束），
   V-B 用**真实文本**（露出最后一个完成段的标签与当前段标签）；实施阶段一律要落成真实节点。
④ V-C 分段控件选中项的轻投影偏离 FR-10 §6「内容页不用阴影」——它是控件滑块不是卡片阴影，
   判据表不统计阴影，故不构成指标违规，如实登记。
⑤ 「card grouping density --domain ux」在 ui-ux-pro-max 库里 **0 命中**；
   改用 "dashboard information density" / "grouped list section" 复核，命中 Color Only / Active State。
