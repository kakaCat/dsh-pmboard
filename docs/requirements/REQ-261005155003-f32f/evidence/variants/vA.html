V-A 单卡报头 · REQ-261005155003-f32f 候选设计

头部 + 状态带 + 操作条合并成一张浅灰卡（圆角 12 / 内边距 16），卡内三格指标用极细竖分隔分栏；Tab 栏降为卡下的次级导航（纯文字 + 选中下划线）；评论折叠成一行摘要。首屏 = 一张卡 + 六个页签。

query：?state=inflight|terminal ｜ ?annot=0 隐藏本说明区（出图用）｜ ?theme=dark 模拟宿主深色主题（浅色岛口径：岛内长相不受影响）。

三版共用同一份标本 DOM（真实 buildReportShell + 真实 13 片 CSS），**只换 CSS 层**， 故三版之间与人看过的改前/改后图之间逐项可比。结构差异靠 CSS 布局（display:contents + order）实现。
