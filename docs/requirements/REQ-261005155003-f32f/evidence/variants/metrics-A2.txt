    · 模块间距 = 相邻模块**内容盒**（边框盒 ± 自身 padding/border）之间的垂直距离，取各段最小值。
      V-A 实测 33px = 上模块下内边距 16 + 发丝线 1 + 下模块上内边距 16；
      V-A2 实测 36px = 上下各 18px 内边距（发丝线已撤，分界只靠间距 + 标题行）。
      V-A 逐段：33 / 33 / 33 / 33 / 33 / 33；V-A2 逐段：36 / 36 / 36 / 36 / 36 / 36。
    · 模块内间距 = 同一模块内「标题行底边 → 正文顶边」的垂直距离，取各模块最大值。

      这正是「读起来像表格」的机械证据；需求文档登记的 1.25 = 另一套口径（模块间 20 ÷ 模块内 16，测于权威原型），
