⚠️ 口径说明：破坏性动作的**绝对左缘**当然随它前面有几个动作而不同（2 动作 207 / 3 动作 293），
  这正是「恒排最后」的定义；不随数量漂移的是**主操作位置**与**危险动作与前一个的间距**

  故不缩进——与其它动作一样贴动作区左缘 97（FR-9 第 4 项"动作组左端恒等于卡片内容区左缘"）；

逐条对照与差异：
1. D-8 三条：原型 44<77（Δ33）、516<1142 ✓ / 真壳 8<39（Δ31）、600<1147 ✓ —— **同向同判据，两处都过**。
   绝对值不同只因两页外层留白不同（原型页有 proto 舞台与 `.wrap` 内边距）。
2. 「动作组左端 = 卡片内容区左缘」：原型 动作格左缘 117 ≠ 卡片内容区左缘 24，差 93
   （= 原型头部自身的内边距 16 + 「← 看板」65 + 间距 12）；真壳 动作格左缘 97 ≠ 20，差 77 = 「← 看板」65 + 间距 12。
   **两侧一致的事实是**：动作**行**（`.dsh-pm-rh-bar`）左缘 = 卡片内容区左缘（原型 40 vs 其头部内容左缘 40；
   真壳 20 vs 20），动作格紧随「← 看板」之后、主操作与动作格左缘齐平。真壳比原型更"贴左"（20 = 卡片内容左缘），
   原型那 40 是它自己头部的内边距。**这条按"动作行左缘 + 主操作 === 动作格左缘"判**（FR-9 第 4 项 + TC-20）。
3. 已撤销的「布局修复层 v2 (1)」：该层把身份行与「创建于 + 窗口」并成一行、动作组与之同排。
   原型里这些规则**仍在文件里**，但被更靠后的 D-8 层覆盖——实测最终态确实是两行（44 / 77），
   故原型**当前读数**与 D-8 一致；写进对照是为了说明"文件里留着旧层"不等于"外观还是旧的"。
4. 原型是**只换 CSS 层**的预览，两处靠 `display: none` 藏（动作条标签、常驻后果节点），DOM 节点仍在；
   真壳按 FR-11 真删标签（见 t10 的对照说明）。这一条与 D-8 无关，登记在 t10 的证据文件里。
