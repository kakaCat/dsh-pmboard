## 明确登记、不再返工的残余（复核者同意不阻塞）

1. **`dispose → reqDetail.reset()` 变异存活**：界面侧另有 `disposed` 守卫，删掉 `reset()` 无可观察差异；
   本轮只覆盖可观察的一半（卸载后迟到响应不写回界面），如实标注。
2. **上游版本号后退**（迁移重编号 / 回滚脚本）时方向性判据不会自愈，页面停在旧全文直至刷新。
3. **重取悬挂窗口内无「更新中」提示**（≤8s 超时后才落错误占位）。
4. **两个判据都不成立时选择「不重取」**（摘要 version 与记录 version 不同源且载荷无 revision）——
   宁可陈旧，不许混源成风暴。

## 结论

三轮复核的全部必修项已闭合（复现 + 变异双向验证）；第三轮判定**可复核通过**。
