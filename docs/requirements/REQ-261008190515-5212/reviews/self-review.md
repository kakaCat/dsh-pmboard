## 3. 主动发现的问题与处置（均由红灯暴露，未静默放过）

1. **链声明行归属迁移**（t-124acb 补记）
   现象：`prompt-tiers` 的「链声明物化」断言要求 heavy 文本含与 `STAGE_CHAIN` 逐字一致的交棒行——
   该行原由 overrides「覆盖 6」提供，收编后消失。
   处置：在自写正文末行按 `chain.ts` 第 59 行**逐字**写入（去掉反引号）。
   教训：**收编 overrides 前先查哪些断言依赖被收编条目**。

2. **探针白名单残留空对象**（t-83bb63 修复）
   现象：删除死条目时留下 `{}`（无 `match`）→ 白名单遍历 `r.match.test` 抛错 → `--specimen` 崩。
   处置：整块删除，改为数组内注释留存「为什么删」。
   教训：**删数组元素后要跑 `--specimen` 之类会遍历该结构的路径**，不能只看主路径 exit 0。

3. **字面判据与说明注释冲突**（t-1a2d1e / t-83bb63 各一次）
   现象：验收判据是 `grep -c <token> = 0`，而注释里为留审计线索写了该 token。
   处置：说明改**指代写法**（「上游 skill 自带的两条辅助脚本路径」），审计线索指向 ATTRIBUTION 档案。
   教训：**字面判据要按字面做到**，同时别把审计信息删掉。

4. **断言钉旧编号**（t-83bb63 扩围修复，来源=全量套件）
   现象：`tests/task-card.test.ts` 断言注入文本含字面 `覆盖 7`——钉的是旧 overrides 编号。
