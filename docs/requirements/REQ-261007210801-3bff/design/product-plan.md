# pmboard 产品规划：聚焦体验与可视化 `serves: DOC-1, DOC-2, DOC-3, DOC-4, DOC-5`

> **TL;DR**：pmboard 能力面已铺得很广（27 工具 / 100+ 需求 / 20+ 机制文档），但缺主线。
> 本规划裁定唯一主攻方向 = **体验与可视化**，未来一段时间只按 §3 的清单顺序立项；
> 还债、自动化、外发三条线全部挂起，直到 §5 的做透判据满足。

```
                 pmboard 能力面（现状，无主线）

        │          │          │          │
        ▼          ▼          ▼          ▼

              痛点最直观 · 每天有体感
```

## 1. 背景与方向裁定 `serves: DOC-2`

维护者自述（2026-10-07）：「想到哪里坐到哪里，没有清晰的规划」「想把精力放到一个方向」。

候选四方向于当日对话中裁定，结论：**C. 体验与可视化**。裁定依据：

- **A 还债稳基**（体检报告 H1–H3、工具面精简）：是必要家务，但不带方向感，做完不知道下一步去哪——挂起，清单已留档随时可取；
- **B 自动化深化**：依赖 H3「单进程假设」裁决，而 H3 属 A 线——现在动会悬空，挂起；
- **C 体验与可视化**：唯一用户是维护者本人，体验痛点每天有体感，且本规划对话内就产生了硬证据（立项弹框被连续取消 3 次）——**选定**；
- **D 产品化外发**：安装门槛与文档完整度未达标，外发前须先还债——离当前痛点最远，挂起。

## 2. 主攻方向定义 `serves: DOC-2`

**体验与可视化** = 让维护者本人在日常使用 pmboard 看板与流水线时：
看得懂（信息架构清晰）、找得到（导航直达）、敢动手（门与弹框可信）。

边界：只动 client 半与交互流程；host 半 API 与状态机不动（见 §4 非目标）。

## 3. 事项清单（按优先级，后续立项严格按此顺序取） `serves: DOC-3`

| # | 事项 | 做什么 | 为什么排这里 | 验收锚点 |
|---|---|---|---|---|
| P1 | **弹框与确认门体验** | 诊断并修复「弹框被连续取消」的根因（时机不对？文案不清？通道打扰？）；让立项三问、产物确认、验收弹框的作答路径顺畅 | 人工门是产品核心机制，门不好用 = 全流程漏风；本规划对话内实测取消 3 次，是最硬证据 | 台账 capture/confirm 留痕中不再出现连续取消；立项到确认完成无需文字兜底路径 |
| P2 | **看板首屏信息架构** | 重排泳道 / 时间线 / 验收单 / 归档区的首屏职责：打开看板第一眼回答「有几条活、各在哪个阶段、哪条在等我」 | 每天第一眼看到的东西；现状是四个视图平铺堆叠 | 打开看板 10 秒内能口述上述三问的答案（可请新窗口 agent 读板验证） |
| P3 | **「卡在哪」一眼可见** | 需求列表/卡片层直接暴露「当前阶段 + 在等谁（人/机器）+ 下一步动作」，不用点进详情页 | 治「想到哪做到哪」的配套：状态可视才有人盯 | 不点进详情页即可说出任意一条进行中需求的阻塞方 |
| P4 | **空态与新手引导** | 新窗口/新项目首次打开看板时的引导与空态文案 | 前三项见效前做这个是本末倒置，故排末位 | 全新项目从零到立第一条需求无死胡同 |

## 4. 非目标（现在不做——新念头来了对照此表拦截） `serves: DOC-4`

- N1 **不修** H1–H3 高危 bug 及工具面精简（属 A 线；清单已在 [工具面体检](../../../strategy-research/reqboard-plugin-audit-2026-10-07.md) 留档）
- N2 **不做**视觉重设计 / 换肤（除非阻塞使用）
- N3 **不做**移动端适配
- N4 **不动** host 半 API、状态机、台账结构（本方向只动 client 与交互流程）
- N5 **不做**外发、发布、对外文档

## 5. 做透判据（全部满足才可换下一个方向） `serves: DOC-5`

| 判据 | 验证方式 |
|---|---|
| J1 连续一周日常使用中「找不到 / 看不懂 / 点错」零记录 | 维护者日记或看板评论留痕 |
| J2 立项三问与确认弹框不再出现连续取消 | 台账 `capture` / `confirm` 留痕查询 |
| J3 打开看板 10 秒内能说出「有几条活、各卡在哪」 | 新窗口 agent 读板测试（可口述复现） |
