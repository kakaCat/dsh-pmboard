## 二、最重要的三条教训（都付出过代价）

1. **不变量优先，别按形态写正则。**
   搬迁类改动的正确抽象是「**不变量**」——例如「测试不得用自身位置推导仓库根」。
   按形态找规律会反复漏：我在 `'..'` 与 `'../'` 的写法差异上栽过**两次**（同一个正则两次 0 命中）。
   换成不变量后，一次清掉整族（违反面 23 → 0），搬迁态新增失败立刻从 30 掉到 4。
2. **跨搬迁比较集合，键必须做路径归一。**
   文件路径在搬迁后必然变化；用「文件路径 :: 用例名」当键，会把**两态都失败**的用例误判为“新增”。
   我因此追了**十几轮幻影失败**；改成 `basename` 归一后，真·新增立刻从 30 归零。
3. **先备份，再搬；搬前自校验。**
   `cp -r tests /tmp/…` 把每次尝试的代价降到「一条命令恢复」；搬前跑 `tsc` + 用例数检查，能在**半迁移态发生之前**发现问题。
