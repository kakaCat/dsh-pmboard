## 一、这次到底结清的是什么（一句话版）

用户侧的痛点是"点一下模型选择器，控件就没了"，三回合没闭环——**卡点不在修，而在取证**：
DSH 的插槽机制把崩溃的席位**静默退役**，界面上只留下一块空白（连报错都不给）。
本次把"取证—定责—沉淀"这条链走通，并给出根因：**已安装的 DSH 客户端内部包不一致**，
与 dsh-pmboard 插件无关（证据见缺陷报告）。
