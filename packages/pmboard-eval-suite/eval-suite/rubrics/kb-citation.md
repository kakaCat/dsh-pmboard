# Rubric：kb 引用一致性（kb-citation）

> 适用用例：**G2**（kb 预算不足只回指针，须按 id 精确补取、不凭碎片臆造） ｜ `serves: FR-1, FR-3`
> 评审对象：agent 在产物（设计文档/回复正文）中对 kb 条目的引用内容，与 kb 原文的对照结果。
> 计分：维度 D4（产物质量）部分；D1 部分（是否先查 kb、是否按 id 补取）由第一层轨迹断言覆盖。

## 评审维度（各 1-5 分）

| 维度 | 1 分锚点 | 3 分锚点 | 5 分锚点 |
|---|---|---|---|
| 引用与原文一致 | 引用内容与 kb 原文矛盾或张冠李戴（把 A 条目的结论安到 B 条目上），或引用的 id 在 kb 中不存在 | 大意对但有转述失真（数字/条件/限定词被改动，如原文"≤2000 字符"被引成"2000 字符左右"），或漏引关键限定条件 | 逐条核对，引用内容与 kb 原文在事实、数字、条件上完全一致；转述不改语义；引用处标注了可核查的条目 id |
| 按 id 精确补取行为 | 预算不足只回指针后，agent 直接凭指针碎片展开臆造正文，全程未按 id 补取 | 有按 id 补取动作但漏了部分条目（引用 3 条只补取 1 条），或补取后仍混入未核实内容 | 凡正文引用的 kb 条目，都在引用前通过 `reqboard_kb(id=...)` 精确取回原文；指针-only 的条目不进入正文，或明确标注"未取回，待补取" |
| 不凭碎片臆造 | 出现 kb 中不存在的事实/数字/规则，且未标注是推断；把 query 命中的一句话扩写成整段"规范" | 无凭空捏造，但有过度推断（由 kb 条目推出原文没有的结论且未声明是推断） | 正文所有事实性断言可溯源（kb 条目/需求文档/明确标注的推断）；推断内容与引用内容清晰区分，不把推测伪装成 kb 原文 |

## 评审输入

喂给评审 LLM 的材料（按序拼接）：

1. 本 rubric 全文；
2. **产物文件**：agent 引用 kb 的产物正文（设计文档/回复，从 `reports/<run-id>/snapshots/G2-<k>/` 取），标出其中引用 kb 的段落；
3. **kb 原文**：被引用条目的完整原文（按产物中标注的 id 从知识层取回，作为对照基准）；
4. **场景脚本**：`scenarios/G2.yml`（含预算不足只回指针的构造方式）+ 轨迹表 `traces/G2-<k>.md` 中 `reqboard_kb` 调用段（供核对"按 id 补取"行为，与第一层断言交叉验证）；
5. **校准样本**：从 `calibration/` 取 ≥3 条本 rubric 的人工标注样本（含至少 1 条"凭碎片臆造"的负样本）做锚定。

## 输出格式

```json
{
  "引用与原文一致": 4,
  "按 id 精确补取行为": 5,
  "不凭碎片臆造": 3,
  "理由": "引文与原文一致；均先按 id 取回；一处由条目过度推断未标注"
}
```

- 维度名必须与上表一致，分值 1-5 整数，「理由」≤50 字；
- **规程**：每条产物评审 **2 次取均值**；评审均值与人工抽样偏差 **>1 分 → 本 rubric 回炉校准**（修订锚点表述，见 `calibration/README.md`）；
- 结果记入 ScoreRecord：`layer2.rubric_scores = {引用与原文一致: 4, ...}`，`layer2.mean` = 各维度均值的平均。
