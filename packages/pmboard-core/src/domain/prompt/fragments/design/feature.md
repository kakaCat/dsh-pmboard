# 类型档 · feature（设计）

- [ ] 设计文档含**接口**签名（参数 / 返回 / 错误码）与**数据契约**（字段 / 类型 / 约束）。
- [ ] feature 必交：interfaces.md 含「接口清单」表、frontend.md 含「组件树」节（缺节被拒）。
- [ ] 写清迁移与兼容设计：数据回填、开关或灰度、回滚路径。
- [ ] 给出四视角（架构 / 接口 / 数据模型 / 测试策略）中适用的部分；契约定不死不许进拆分。
- [ ] 有原型的 UI 需求：`design/frontend.md` 指向 `prototypes/INDEX.md` 的权威路径与 `#FR-N` 锚点（锚点单独记账、不进 serves），并引相关 D-x。
